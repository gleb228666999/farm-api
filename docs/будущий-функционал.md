## 1. 📱 ПРИЛОЖЕНИЕ НА ANDROID (вместо Telegram-алертов)

**Почему:** Telegram заблокирован. Алерты (этап 3 из старого роадмапа) удалены из плана —
вместо них хозяин делает **отдельное приложение на Android**.

Приложение может жить на одном из фарм-телефонов (или на любом другом) и просто ходит
по HTTP к серверу. Ничего на сервере переделывать не надо — API уже готов:

| API приложения | Что даёт |
|---|---|
| `GET /api/devices` | кто онлайн, батарея, версия клиента, возраст ключа 🔑 |
| `GET /api/events?device_id=...&limit=...` | события фарма (байпас, ключ, перезапуски окон) |
| `GET /api/groups` | группы устройств |
| `POST /api/groups/<имя>/send` | кнопки управления из приложения |
| `POST /api/update` | обновить клиента |

**Чеклист приложения:**
- [ ] Список телефонов + статусы (онлайн/батарея/ключ)
- [ ] Лента последних событий фарма (обновление раз в 30с, `GET /api/events?limit=50`)
- [ ] Пуши: телефон офлайн > 3 мин / `bypass.fail` / телефон вернулся
      (реализация: сервис в приложении опрашивает `/api/devices` и `/api/events`,
       локальные уведомления Android — без FCM, работает без Google-сервисов)
- [ ] Кнопки: farm ▶/⏹, ⬇ APK, ⬆ (на группу или на всё)
- [ ] Хранить адрес сервера в настройках приложения

**Идеи на потом:** виджет на рабочий стол (кол-во онлайн + 🔑 возраст),
QR-код для быстрой настройки адреса сервера.
