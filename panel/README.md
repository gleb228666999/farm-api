# 🚜 Farm Panel — каждая функция отдельной кнопкой

Веб-панель для **farm-api**: можно тестировать каждую функцию по отдельности —
фарм, байпас, регу акков, сбор урожая, проверку кук, сервисы и т.д.

Панель подключается к **Farm Server** (main.py, FastAPI, порт 8000) по HTTP —
запросы идут через встроенный прокси `/api/farm`, так что CORS не мешает.

## 🚀 Запуск

### Продакшн (рекомендуется — отклик кнопок заметно шустрее, чем в dev)

```bash
cd panel
npm install
npm run build
npm start          # панель: http://IP-панели:3000
```

`npm run dev` годится только для отладки — на слабой машине каждый запрос
в dev-режиме компилируется на лету и тормозит («кнопки долго отвечают»).

### Адрес сервера фермы

Панель подставляет его САМА: `http://<хост, с которого открыта панель>:8000`.
Если сервер фермы на другой машине — впиши адрес в шапке панели и нажми
«Проверить связь» (сохранится в браузере).

### Dev-режим

```bash
cd panel
npm install        # или bun install / pnpm install
npm run dev        # панель: http://localhost:3000
```

Сервер фермы должен быть запущен:

```bash
cd ..              # корень репо
python main.py     # Farm Server: http://0.0.0.0:8000
```

В шапке панели укажи адрес сервера фермы (например `http://1.2.3.4:8000`) —
он сохранится в браузере (localStorage).

## 🧰 Кнопки по функциям (вкладка «Устройства»)

| Кнопка | Что делает | Как работает |
|---|---|---|
| 🚜 Фарм ▶ | старт фарма | задача `service.start farm` |
| 🚜 Фарм ⏹ | полный стоп фарма (глушит и регу, закрывает роблоксы) | задача `service.stop farm` |
| 🔓 Байпас | принудительный байпас: сброс 24ч кулдауна → фарм ⏹ → фарм ▶ | `exec` правит `info/farm_state.json` (`last_key_time=0`) |
| 📊 Статус | статус сервисов (farm/rega/demo) | задача `service.status` |
| 🆕 Рег акков | авторегистрация (20 попыток, 2×10, отдых 15 мин) | задача `rega.start` |
| 🍪 Проверка кук | быстрая проверка + починка кук из пула/архива | задача `cookie.check` |
| 🌾 Сбор ▶ | окно сбора урожая (минуты + placeId) | задача `harvest.start` |
| 🌾 Сбор ⏹ | снять окно сбора | задача `harvest.stop` |
| 📢 Ping | проверка связи | задача `ping` |
| ⬆ Update | обновить клиент по воздуху | задача `update` |
| ⬇ APK | установить/обновить APK | задача `apk.update` |
| 📄 Логи | читать любой файл телефона (farm.log и т.п.) | задача `file.read` |
| 💻 Exec | произвольная shell-команда | задача `exec` |
| ♻️ Restart | перезапуск клиента | задача `restart` |
| ⛔ Halt | полная остановка телефона | задача `halt` |

## 🌐 Глобальные кнопки (вкладка «Команды»)

- 🆕 **Рега сейчас** — оркестрация сервером: farm ⏹ всем → 30с → rega.start
- 🌾 **Сбор сейчас** — HOLD: фармеры в приватках до «НОВЫЙ ЦИКЛ»
- 🍪 **Проверка кук всем** — всем онлайн-фармерам
- ⬆ **Update всем** — обновление клиента на всех
- 📢 Broadcast — Фарм ▶/⏹ всем, Демо ▶/⏹ всем, Ping всем, кастомная задача
- ⏳ **Снять отложенные** — очистить очередь команд для офлайн-телефонов

## ⏳ Отложенные команды (v0.11) — «Стоп фарм всем» работает даже если телефоны спят

Команды «для всех» уходят только телефонам на связи. Раньше если телефон был офлайн
(сел/уснул Wi-Fi), команда **терялась навсегда** — фарм продолжал крутиться
(«нажал — ничего не происходит»). Теперь сервер:

- **«⏹ Стоп фарм всем»** — онлайн-телефонам сразу, офлайн — откладывает
  (`pending_commands.json`, TTL 12ч); при подключении телефон получает стоп автоматически;
- **🛡 тумблер «Рега акков»** — состояние тоже догоняет офлайн-телефоны при hello;
- **«Сбор сейчас» / «НОВЫЙ ЦИКЛ» / «Рега сейчас»** снимают отложенные стопы — новое
  намерение важнее старого;
- тосты показывают ЧЕСТНО: кому доставлено, у кого связь рвётся, кто получит команду позже;
- панель показывает бейдж «⏳ ждёт команд: N» у офлайн-устройств (вкладка «Устройства»)
  и баннер с количеством отложенных (вкладка «Команды»).

## 🗂 Остальные вкладки

- **Пул кук** — счётчики, добавление (nick:/pass:/.ROBLOSECURITY=...), удаление, пул↔архив, тест claim/report
- **События** — лента событий фарма/реги из SQLite, фильтры по типу/устройству, очистка
- **Группы** — создание групп устройств, отправка задач группе
- **Расписание** — рега/сбор по МСК, интервал проверки кук, состояние
- **Результат** — проверка результата по task_id
- **Журнал** — все действия панели с ответами сервера (раскрывается JSON)

## 🧪 Тест без телефонов

В корне репо есть `mock_phone.py` — фейковый телефон для проверки панели:

```bash
python main.py            # терминал 1 — сервер
python mock_phone.py      # терминал 2 — фейковое устройство "0"
cd panel && npm run dev   # терминал 3 — панель
```
